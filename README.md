Description
This is a simple personal website created using HTML and CSS. The project demonstrates basic web development skills, including creating a webpage, linking an external stylesheet, displaying an image, and building a simple contact form.

Features
- Personal introduction
- List of hobbies
- Contact form with Name and Email fields
- Styled using an external CSS file
